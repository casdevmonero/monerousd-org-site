macOS Users: Allow App to Run

MoneroUSD is not signed with an Apple Developer certificate, so macOS will show "damaged and can't be opened." To fix this, open Terminal and run:

sudo xattr -rd com.apple.quarantine "/Applications/Monero USD Wallet.app" && sudo codesign --force --deep --sign - "/Applications/Monero USD Wallet.app"

This removes the quarantine flag and ad-hoc signs the app locally. You will be prompted for your Mac password. If it still doesn't open, go to System Settings → Privacy & Security and click "Open Anyway" next to the MoneroUSD message.

PQ FCMP++ — Privacy That Survives Quantum

MoneroUSD's own post-quantum Full-Chain Membership Proofs — the strongest transaction privacy ever shipped, and the only kind a quantum computer can't unwind.

What is PQ FCMP++?

PQ FCMP++ (post-quantum Full-Chain Membership Proofs) lets every spend prove it references a real, unspent note from the entire chain — without revealing which one. Instead of a small ring of decoys, your anonymity set is every note ever created.

Why It Matters

Ring signatures use 11–16 decoys, giving statistical heuristics a foothold. With PQ FCMP++ the anonymity set is millions of notes, so chain analysis is cryptographically impossible — and because it's post-quantum, it stays that way even against a future quantum adversary harvesting today's chain.

How It Works

Membership is proven against a post-quantum commitment tree using Poseidon2 hashing and a WHIR zero-knowledge proof — no elliptic curves anywhere. Spends are gated by an O(1) nullifier accumulator, so double-spends are impossible while the note you spent stays unlinkable.

Performance

Despite covering the whole chain, the proof is a constant ≤1.8 MB and verifies in milliseconds on phone-class hardware — at any chain height. Privacy and scalability, with no trade-off.
