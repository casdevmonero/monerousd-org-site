MoneroUSD Veil

Encryption hides what you say. The Veil hides who you say it to.

Even a perfectly private payment can be traced by watching the network: which computer sent it, and when. The Veil is MoneroUSD's own post-quantum mix network, built so that watching the wires tells an observer as little as watching the chain.

Partly built · in testing on real nodes

Sending

Three hops, one layer each.

Your wallet wraps a packet in three layers of encryption, one per relay. Each relay can remove only its own layer, so it learns only the hop before and after it. Every packet has the same size; each hop checks a MAC and refuses replays and tampered packets.

Relays send cover traffic at a constant rate, so a real packet is one among many identical ones. And your payment never leaves from your own node: it's pushed through the mix to a random node, which announces it as its own.

Reading

Private reads: the server doesn't learn what you asked for.

Hiding who asked is half the job; a server that knows which page or record you fetched still learns something. The Veil reads with private information retrieval (PIR), in tiers, fastest first:

  1. Local: data every node already holds — an instant read, nothing leaves your device.
  2. Two-server PIR: two nodes each scan a whole bucket with a key that looks random; combined, the answers give you your item. Neither learns which item it was.
  3. Single-server PIR with a small client hint, for sublinear server work.
  4. The mixnet, for anything else.
Built for a hostile world

Attacks, and where each defence stands.

The limits, stated plainly.

No network can promise perfect anonymity against everyone. Anonymity is bounded by the crowd you hide in, and there is a proven trade-off between anonymity, bandwidth and delay. Someone who cuts every link a node has can stop any network — the Veil's aim is that nothing short of that takes it down, and that it heals by itself once links return.

The Veil's own launch gate: every row above built with a real-node check, an outside audit of the mix code, a run over real internet links, and a public soak.
