Run a node

One kind of node. Built to stay small.

There are no tiers on MoneroUSD: every node mines, verifies, proves and relays. Validators are the same node with a SAT bond.

Public testnet is live

Joins at the tip

A new node checks one recursive proof of the whole chain and starts at the tip. A restart resumes from where it left off — no replay of history.

Constant state

Node state stays the same size as the chain grows: 0.9 GB memory, 290 MB disk, 42 MB binary. Phone-class hardware can run a full node.

Earns its keep

Nodes that produce blocks earn SAT, and a share of fees through the miner pool. Bond SAT to validate custody and finality.

Requirements

Hardware

CPU: Any 64-bit (x86-64 or ARM64)
RAM: 2 GB free (measured peak 1.4 GB)
Disk: 1 GB free (measured 290 MB)

Network

Any connection that reaches Tor. No open ports, no public IP. Every link is a Tor v3 onion service.

Software

macOS (Apple Silicon), Linux (x86-64/ARM64), Windows via WSL2. No dependencies — the binary includes Tor.

Option 1: Use the wallet

The wallet runs the node for you. Download and open it — the node starts automatically and connects to the testnet.

Download wallet (macOS) All releases

macOS asks you to allow the app once (it is not notarized by Apple yet): open Terminal (press ⌘ Space, type Terminal, press Return), paste this and press Return:

xattr -dr com.apple.quarantine "/Applications/MoneroUSD Wallet.app"

Option 2: Build from source

Requires a recent stable Rust toolchain.

# Clone the repository
git clone https://github.com/casdevmonero/monerousd.git
cd monerousd/monerousd-node-zkdag

# Build (first build compiles the prover — takes a while)
cargo build --release --bin usdmd-node

# Start the node
MONEROUSD_NET=testnet MONEROUSD_RPC_PORT=27780 \
  ./target/release/usdmd-node serve

The node stores its data in ~/.usdmd-node/. It creates its own Tor hidden service and finds peers automatically.

Becoming a validator

A validator is the same node with a SAT bond. The node derives its validator key from its own seed — no extra setup, no passwords. Bond test SAT from a mined reward or the faucet:

MONEROUSD_NET=testnet MONEROUSD_RPC_PORT=27780 MONEROUSD_VALIDATOR_BOND=1 \
  ./target/release/usdmd-node serve
