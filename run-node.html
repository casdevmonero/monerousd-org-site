Run a node

One kind of node. Built to stay small.

There are no tiers on MoneroUSD: every node mines, verifies, proves and relays. Validators are the same node with a SAT bond.

Node downloads open with the public testnet

Joins at the tip

A new node checks one recursive proof of the whole chain and starts at the tip. A restart resumes from where it left off — no replay of history.

Constant state

Node state is designed to stay the same size as the chain grows, so phone-class hardware can run a full node. Sizes are being measured on real nodes.

Earns its keep

Nodes that produce blocks earn SAT, and a share of fees through the miner pool. Bond SAT to validate custody and finality.

Earlier instructions withdrawn

This page used to describe an older node with a different design. Those instructions no longer apply and have been removed. The node for the current design ships with the public testnet, with install steps for desktop and servers. Check the testnet status.
